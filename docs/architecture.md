## 模块清单

| 层 | 模块 | 文件 | 功能 |
|---|---|---|---|
| 前端 | 上传 | `App.jsx` | PDF 拖拽上传 → POST /upload |
| 前端 | 问答 | `App.jsx` | SSE 流式对话 + 引用高亮 + 来源折叠 |
| 前端 | 调优 | `App.jsx` | chunk_size/阈值调节 + 实验记录表 |
| 后端 | API | `main.py` | 10 个 REST 路由 + CORS + 错误处理 |
| 后端 | 数据库 | `database.py` `models.py` | SQLAlchemy + SQLite (文档/对话) |
| 后端 | 加载 | `document_loader.py` | PyPDFLoader + RecursiveCharacterTextSplitter |
| 后端 | 向量 | `vector_store.py` | httpx → Ollama /api/embed + FAISS 持久化 |
| 后端 | 链 | `rag_chain.py` | 检索 → Prompt 组装 → Ollama 生成 |
| 后端 | 配置 | `config.py` | 8 个环境变量，默认值适配本地开发 |
